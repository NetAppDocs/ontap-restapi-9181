:imagesdir: ./media/

Manage physical and logical storage, including aggregates, volumes, LUNs, qtrees, snapshots, quotas, and storage efficiency. Use these endpoints to allocate and optimize storage resources within your ONTAP environment.

== Overview

The ONTAP storage APIs can be used to manage physical and logical storage. This includes management of aggregates, volumes, LUNs, qtrees, snapshots, quotas, and storage efficiency.
