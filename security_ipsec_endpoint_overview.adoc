= View and update IPsec configuration
:imagesdir: ./media/

[.lead]
Retrieve and modify the IPsec configuration to manage security settings for your network connections. Use the endpoints to check current IPsec status or update configurations as needed.

== Overview

The following operations are supported:

* GET to retrieve the IPsec status: GET security/ipsec
* Patch to update IPsec status: PATCH security/ipsec
