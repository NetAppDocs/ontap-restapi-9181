= View suspect files generated by anti-ransomware
:imagesdir: ./media/

[.lead]
Retrieve details on files recently flagged as potential ransomware threats using the suspect GET API. Use this endpoint to monitor and respond to suspicious activity in your environment.

== Retrieving information on suspected files

The suspect GET API retrieves a list of recently suspected files potentially attacked by ransomware.
