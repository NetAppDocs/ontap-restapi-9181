= Delete suspect files
:imagesdir: ./media/

[.lead]
Use the suspects DELETE API to remove suspect files from a volume's list of potential issues. This helps maintain the integrity and reliability of your storage environment.

The suspects DELETE API clears all the suspect files for a volume from the list of potential suspects.
